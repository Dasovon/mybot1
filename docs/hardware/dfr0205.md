# DFR0205 — DC-DC Buck Converter / Power Distribution Board

## Role in This Project

The DFR0205 is an alternative power distribution option to the RPI5 PD Power Hat. It accepts a battery input, provides an adjustable regulated output for the Pi and logic, and passes through raw battery voltage for motor power.

See [rpi5_pd_power_hat.md](rpi5_pd_power_hat.md) for the other power option. **One or the other will be used — not both.**

---

## Key Specs

| Property | Value |
|---|---|
| Manufacturer | DFRobot |
| Part number | DFR0205 |
| Input voltage | 3.6V – 25V DC |
| Output voltage | Adjustable 3.3V – 25V (must be lower than input) |
| Max output current | 5A |
| Max output power | 25W (5A × 5V) |
| Switching frequency | 350 kHz |
| VIN passthrough | Yes — raw input voltage available on separate connector |
| Power switch | Onboard ON/OFF button |
| Dimensions | 46 × 50 × 20 mm |

> ⚠️ Output voltage must always be set **lower than input voltage**. The DFR0205 is a buck (step-down) converter only — it cannot boost.

## Connectors / Interfaces

| Connector | Signal | Use in this project |
|---|---|---|
| Input | Battery + and − | 12V LiPo or equivalent |
| Output (regulated) | Adjusted voltage + GND | 5V to Raspberry Pi (USB-C or header) |
| VIN passthrough | Raw battery voltage + GND | Motor power → TB6612FNG VM pin |
| ON/OFF button | — | Robot main power switch |

## Power Architecture with DFR0205

```
Battery (3S LiPo ~12V)
    └── DFR0205 INPUT
            ├── OUTPUT (regulated 5V, up to 5A / 25W)
            │       └── Raspberry Pi 5 (USB-C or GPIO 5V pin)
            │               ├── Pi USB-A  →  ESP32-S3    (power + micro-ROS serial)
            │               ├── Pi USB-A  →  RPLidar A1  (power + data, USB 2.0)
            │               └── Pi USB-A  →  RealSense D435 (power + data, USB 3.0)
            └── VIN passthrough (raw ~12V)
                    └── TB6612FNG VM pin (motor power)

TB6612 logic VCC  →  ESP32 3V3 pin
Common ground: Battery −, DFR0205 GND, Pi GND, ESP32 GND, TB6612 GND — all one rail.
```

## Voltage Setting

Output voltage is set by adjusting a resistor configuration or onboard switch (refer to DFRobot wiki for your specific board revision). **Set to 5V before connecting the Raspberry Pi 5.**

Verify with a multimeter across the output terminals before plugging in the Pi.

## Comparison vs RPI5 PD Power Hat

| Property | DFR0205 | RPI5 PD Power Hat |
|---|---|---|
| Max power | 25W (5A × 5V) | 40W (8A × 5V) |
| Pi 5 connection | USB-C cable or header | USB PD 3.0 (negotiated) |
| Pi 5 power headroom | Tight — Pi 5 alone can draw ~25W at peak | Comfortable — 40W leaves margin |
| Voltage output | Manually adjustable | Fixed 5.15V (USB PD) |
| VIN passthrough | Yes | Yes (screw terminal) |
| Input range | 3.6–25V | 9–24V (DC barrel) or USB PD |
| Physical form | Standalone board, wired connections | HAT-style, mounts on Pi |

**Recommendation:** The RPI5 PD Power Hat is the better fit for this build due to higher power headroom (40W vs 25W) and native USB PD delivery. The DFR0205 is a valid fallback.

---

## Wiring Notes

- DFR0205 regulated 5V output → Raspberry Pi 5 via USB-C
- Pi USB ports power: ESP32-S3, RPLidar A1, RealSense D435
- DFR0205 VIN passthrough → TB6612FNG VM (motor supply)
- All grounds tied together at DFR0205 GND terminal
